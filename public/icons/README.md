# Scopwise icon system

The Scopwise icon family uses a 24 x 24 grid, a 1.75 px stroke, rounded terminals, and `currentColor`. Familiar interaction icons follow established Lucide conventions; product icons are custom to Scopwise.

## Sizes

- 16 px: compact navigation and metadata
- 20 px: buttons and form controls
- 24 px: dropdowns, feature lists, and standard interface actions
- 32 px: standalone feature emphasis

Do not scale strokes independently. Product-dropdown icons should sit in 40 x 40 containers using Map Sky, Rules Lavender, and Review Mint surfaces. Icons remain Scopwise Ink by default.

## Families

- `navigation`: menu, close, back, and dropdown controls
- `actions`: CTA arrows, play, selection, search, filter, download, copy, calendar, and email
- `products`: Scopwise Map, Rules, and Review
- `platform`: agents, data, apps, workflows, access, evidence, reviewers, trust, and enterprise context
- `social`: LinkedIn, X, GitHub, YouTube, and Instagram footer marks

Use inline SVG or an image component. For inline SVG, the `currentColor` stroke inherits normal, hover, focus, disabled, and reverse-theme colors from the parent control.

Only show a social icon in the production footer after the corresponding official Scopwise profile has been created and approved. Social links open in a new tab and require a platform-specific accessible label.
